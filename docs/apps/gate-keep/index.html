Latent-summary math (simplified, mirrors gate_keep/compress.py)

w = softmax(s_evicted / temp)  →  k_bar = Σ wᵢ·Kᵢ, v_bar = Σ wᵢ·Vᵢ (weighted barycenter of tail)
k_mem = P·Pᵀ·k_bar · (‖k_bar‖/‖P·Pᵀ·k_bar‖) with random orthonormal sketch P (8-d, norm-preserved) — appended as one extra key.
Error = probe-query attention-output residual: ‖attn(K)·V − attn(K')·V'‖ / rms(V), probe q = mean(K). Same denominator for drop vs memory, so ordering is fair.
